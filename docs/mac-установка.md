# Установка на macOS

Приложение пока не подписано аккаунтом разработчика Apple, поэтому macOS при
первом запуске скажет, что «не удаётся проверить разработчика» или что файл
«повреждён». Ни то, ни другое не про сам файл — так система встречает любую
программу без подписи за 99 $ в год. Ниже — как её пропустить.

## Что скачивать

| Файл | Кому |
|---|---|
| `Proxya-Anty_1.0.1_aarch64.dmg` | обычная установка, приложение переезжает в «Программы» |
| `Proxya-Anty_1.0.1_aarch64_portable.zip` | портативная: профили, куки и вход лежат рядом с приложением |

Оба — для Apple Silicon (M1 и новее). Под Intel-маки сборки нет.

## Обычная установка

1. Открыть `.dmg`, перетащить **Proxya Anty** в **Программы**.
2. Открыть **Терминал** (Spotlight → «Терминал») и выполнить одну строку:

   ```bash
   xattr -dr com.apple.quarantine "/Applications/Proxya Anty.app"
   ```

3. Запустить приложение обычным двойным щелчком.

Строка снимает метку «скачано из интернета», которую macOS вешает на любой файл
из браузера. Она снимается один раз и на все последующие запуски.

### Без Терминала

Если командная строка не хочется:

1. Щёлкнуть по **Proxya Anty** правой кнопкой (или Control + щелчок) → **Открыть**.
2. В окне с предупреждением нажать **Открыть** ещё раз.

На macOS Sequoia (15) и новее этого пункта в меню больше нет. Там: запустить
приложение обычным щелчком, получить отказ, затем **Системные настройки** →
**Конфиденциальность и безопасность** → пролистать вниз до строки про Proxya
Anty → **Открыть всё равно**.

## Портативная

1. Распаковать `.zip` — внутри папка с `Proxya Anty.app` и `proxya-data` рядом.
2. Снять карантин со всей папки:

   ```bash
   xattr -dr com.apple.quarantine ~/Downloads/Proxya\ Anty
   ```

3. Запускать `.app` прямо оттуда.

Всё, что приложение пишет, остаётся в `proxya-data` рядом с ним: профили,
куки, вход в аккаунт, движок. Секретные файлы зашифрованы ключом из macOS
Keychain, поэтому простое копирование этой папки на другой Mac не переносит
авторизацию и прокси-пароли. **Папку `proxya-data` не переименовывать и не
выносить из папки с приложением** — по ней приложение понимает, что оно
портативное; без неё оно начнёт писать в
`~/Library/Application Support/proxya-anty`, как обычная установка.

Пока сборка не подписана постоянным Apple Developer ID, после обновления macOS
может один раз спросить разрешение нового бинарника на доступ к прежней записи
Keychain. Разрешите доступ, чтобы приложение смогло прочитать уже сохранённые
зашифрованные настройки.

## Если macOS всё равно ругается

**«Программа повреждена и должна быть удалена».** Это тот же карантин, просто
формулировка другая — она появляется, когда архив распаковали штатным
Архиватором. Команда `xattr -dr com.apple.quarantine` из пунктов выше лечит и
её. Проверить, что метка снята:

```bash
xattr "/Applications/Proxya Anty.app"
```

Пустой вывод — метки нет.

**«Не удаётся открыть, так как разработчик не может быть проверен».** Карантин
не снят. Убедиться, что путь в команде — тот самый (пробел в «Proxya Anty»
нужно экранировать или брать путь в кавычки).

**Ничего не происходит по двойному щелчку.** Посмотреть, что говорит система:

```bash
"/Applications/Proxya Anty.app/Contents/MacOS/proxya-anty"
```

Приложение напишет причину в терминал.

## Что дальше

При первом запуске приложение скачает движок (~200 МБ) — это патченый Chromium,
без него профили не поднимаются. Скачивание идёт в фоне, прогресс виден на
экране настроек.
